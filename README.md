# 佛尔思和休 · 同人作品站

基于「佛尔思和休」主题的同人创作与阅读平台。支持作品发布、章节式阅读、分类检索、标签发现、评论、收藏与作家后台管理，PC / 移动端响应式一致体验。

## 运行

```bash
cd foersi-hexiu-fanverse
node server.js
# 打开 http://localhost:3000
```

> 自定义端口：`PORT=3001 node server.js`

零依赖、零构建：纯 Node.js 内置模块 + 原生前端，无需 `npm install`。

## 目录结构

```

├── server.js            # 入口：HTTP 服务 + API + 静态资源

├── lib/auth.js          # 密码哈希(scrypt) + 会话令牌
├── data/db.json         # 运行时数据（删除即重置）
├── public/
│   ├── index.html       # 首页（佛尔思焦点/分类/标签云/搜索）
│   ├── browse.html      # 书库（主分类/类型/分级/标签/搜索/排序/分页）
│   ├── work.html        # 作品详情（章节目录+评论+收藏+Kudos+作者卡）
│   ├── read.html        # 章节阅读（上下章/字号/主题/年龄门控）
│   ├── auth.html        # 登录 / 注册
│   ├── dashboard.html   # 作家后台（作品与章节管理+数据概览）
│   ├── author.html      # 作者主页（作品聚合/统计/关注）
│   ├── notifications.html # 通知中心（评论/收藏/Kudos/关注）
│   ├── characters.html  # 角色志（佛尔思×休 设定与关系图谱）
│   ├── about.html       # 关于本站
│   ├── legal.html       # 版权与非官方声明 / 作者权益
│   ├── css/style.css    # 响应式样式 + 明/暗主题
│   └── js/              # common.js 公共库 + 各页脚本
├── migrate-v2.js        # 数据迁移（分类→类型，补分级等字段）
├── seed-realworks.js    # 真实成稿导入脚本（幂等）
├── 方案.md              # 完整方案说明
├── 功能完善总结.md      # 佛尔思中心向重构与功能现状
├── 设计分析报告.md      # 设计诊断与 P0/P1/P2 待办
└── README.md
```

## 功能清单

- 分类与检索：佛休主分类 + 小说/短篇/设定 3 类作品类型、标签云、关键词搜索、分级/状态/排序/分页
- 章节阅读：目录跳转、上一章/下一章、字号与主题调节
- 作家后台：注册登录、作品增删改、章节增删改、数据概览与里程碑
- 互动：评论、收藏（toggle）、🌟 Kudos、标签系统、热门排序、关注作者、通知中心
- 创作者保护：全站署名（作者名+头像+主页链接）、作者主页、版权与权益条款
- 内容合规：分级徽章（G/T/M/E）+ 成熟内容阅读前年龄确认
- 响应式：导航折叠、网格自适应、阅读视图、表格卡片化、移动端搜索常驻

详见 `方案.md`。
